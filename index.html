About [-]

yurei es un productor musical, artista visual y miembro del colectivo vritni que junta la musica y la estética digital como una sola experiencia. Su trabajo es un cruce constante entre disciplinas artísticas desde la producción musical, hasta el diseño de narrativas inmersivas a través del VJing, la dirección visual de escenarios y el desarrollo de VFX para proyectos audiovisuales.

Servicios disponibles

Live VJing

Mezcla visual en tiempo real sincronizada al ritmo del show.

Visual Direction

Diseño de narrativa estética y coordinación con iluminación + Visuales personalizadas

VFX & Visualizers

Creación de piezas visuales, simulaciones y renders para lanzamientos.

Instalaciones Interactivas

Sistemas visuales interactivos mediante sensores y programación creativa.

Clases de Vjing

Tutorias personalizadas para el aprendizaje de la técnica de Vjing usando Touchdesigner

Desarrollo web

Sitios web y aplicaciones web interactivas para artistas
